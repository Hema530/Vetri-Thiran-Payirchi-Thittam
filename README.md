 Script-Controlled ACL – Restrict Record Access

## Project Overview

This project demonstrates the implementation of Script-Controlled Access Control Lists (ACLs) in ServiceNow.

The project focuses on controlling access to records based on user roles and conditions using ACL configurations and scripts.

## Project Objective

The main objective of this project is to restrict record access and provide appropriate permissions to users based on their roles and access requirements.

## Technologies Used

- ServiceNow
- Access Control Lists (ACL)
- JavaScript
- ServiceNow Developer Instance

## Project Milestones

### Milestone 1 – Creation of Users and Roles
Created the required users and roles in ServiceNow to manage access permissions.

### Milestone 2 – Tables Creation
Created the required custom table to achieve the project requirement.

### Milestone 3 – Access Control List – READ
Configured READ ACL to control which users can view the records.

### Milestone 4 – Access Control List – CREATE
Configured CREATE ACL to control which users can create records.

### Milestone 5 – Access Control List – WRITE
Configured WRITE ACL to control which users can modify records.

### Milestone 6 – Access Control List – DELETE
Configured DELETE ACL to control which users can delete records.

### Milestone 7 – Conclusion
Successfully implemented script-controlled access restrictions using ServiceNow ACLs.
